# 機能仕様（SPEC）

対象: 米国株（NYSE / Nasdaq）の引け後サマリを **Web ページ（GitHub Pages）** に出し、**Discord** に要約とURLを送る。
データ契約: `src/usmarket/models.py` の `DailySummary`（D-02）。

---

## 1. 実行タイミングと入力

| 項目 | 仕様 |
|---|---|
| 実行 | 平日の米国市場の引け（16:00 ET）後。UTC 20:47（夏時間のみ有効）→ 21:33 → 22:33（最終）、翌 1:17 UTC に時間外取引の終了後の更新（D-22・D-24） |
| 日本時間の目安 | 夏時間: 05:47 / 06:33 / 07:33、更新 10:17。冬時間: 06:33 / 07:33、更新 10:17 |
| 営業日判定 | 土日・NYSE の休場日（`holidays.financial_holidays("NYSE")`）は実行しない。短縮取引（13:00 ET 引け）にも対応 |
| 何度実行しても同じ結果 | 同じ日付の `data/daily/YYYY-MM-DD.json` があり、欠損がなければスキップ。`--force` で作り直す |
| 鮮度チェック | S&P500（^GSPC）の最終日付 ≠ 対象日 → 終了コード 75（再試行してよい失敗） |

## 2. データ取得（collect）

| データ | 取得元 | 頻度 | 備考 |
|---|---|---|---|
| 指数・先物・VIX・為替・世界の指数・商品・暗号資産 | yfinance（`config/indices.yaml`） | 日次 | |
| 米国債利回り 3ヶ月・5年・10年・30年 | yfinance（^IRX / ^FVX / ^TNX / ^TYX） | 日次 | 四本値あり |
| 米国債利回り 2年 | 米財務省 Daily Treasury Par Yield Curve（CSV） | 日次 | 公式値。引け後に公表 |
| 銘柄マスタ | SPDR S&P 500 ETF（SPY）の日次保有銘柄 xlsx ＋ Wikipedia「List of S&P 500 companies」 | 週1回（キャッシュ） | ティッカー・ウエイト／社名・GICSセクター・CIK |
| 個別株の日足 | yfinance | 日次（差分） | 100銘柄ずつ・欠けた分を再取得（D-05） |
| 株価履歴キャッシュ | `.cache/prices/bars.parquet` | 日次で追記 | 初回は約400日分。52週高安・200日線に使う |
| セクターETF | yfinance（XLK など Select Sector SPDR 11本） | 日次 | 補助指標 |
| テーマ銘柄 | yfinance（`config/themes.yaml`） | 日次 | S&P500以外や ADR も可 |
| IPO（動的テーマ） | Nasdaq IPO カレンダー API | 日次（過去月はキャッシュ） | SPAC・小型案件を除く |
| 8-K（決算・重要開示） | SEC EDGAR の最新提出 Atom フィード | 日次 | `SEC_USER_AGENT` が設定されている場合のみ |
| 時間外取引の価格 | yfinance（5分足・時間外込み） | 日次 | 引け後に 8-K を出した銘柄だけ |
| ニュース | RSS（`config/news_feeds.yaml`） | 日次 | 前営業日の引け以降の見出し |

## 3. 集計（analyze）

- **Quote**: 終値、前日比、騰落率、5日・20日の騰落率、直近20本のスパークライン、基準日（日本・欧州・アジアや為替は日付がずれる）
- **セクター（GICS 11）**: S&P500構成銘柄の騰落率を SPY の保有比率で加重した推計値（D-04）、中央値、上昇・下落数、S&P500に占める比率、セクターETFの騰落率、寄与度の上位・下位3銘柄
- **テーマ**: 構成銘柄の騰落率の単純平均、上昇比率、全メンバー（騰落率の降順）、関連ニュース数
- **騰落**: S&P500構成銘柄の値上がり・値下がり・変わらずの数、騰落レシオ(25日)、52週高値・安値の更新数、50日線・200日線を上回る銘柄の割合
- **ランキング**: 値上がり率・値下がり率・売買代金（終値×出来高で近似）・出来高急増（直近20日平均比）の上位10銘柄。値上がり率・値下がり率・出来高急増は売買代金1億ドル以上に限る
- **履歴**: セクター・テーマの直近20営業日の日次騰落率（ヒートマップ用）
- **8-K**: 項目番号（Item 2.02＝決算など）で分類し、注目の項目だけを時価総額の大きい順に最大40件。前日引け〜当日引けは当日の騰落率、引け後は時間外取引の価格と終値の比較を付ける
- **コメント**（ルールベース）: 「S&P500は±x.xx%、NASDAQ総合は…、NYダウは…。A・Bが上昇を主導し、Cが軟調。テーマでは「D」が強い。VIXは…、米10年債利回りは…」。値上がり銘柄の比率が80%以上・20%以下なら「全面高/全面安」を付ける
- **警告**: カバー率95%未満、金利データの欠け、ニュースや EDGAR の取得失敗など

## 4. 出力

### 4.1 サイト構成
```
site/
  index.html            → 最新日へリダイレクト
  YYYY-MM-DD/index.html → 日次ページ（CSS/JSはインライン化し、1ファイルで完結）
  archive/index.html    → 月ごとの一覧（S&P500・NASDAQ・ダウの騰落率）
  trends/index.html     → 期間別騰落率・累積推移・60日ヒートマップ
  data/charts.json      → 拡大チャート用（四本値。リポジトリにはコミットしない）
  data/trends.json
```

### 4.2 日次ページ（DESIGN.md 参照）
① 日付・警告・コメント → ② 米国指数タイル＋騰落 → ③ セクター（＋牽引銘柄とETF）→ ④ テーマ → ⑤ 20日ヒートマップ → ⑥ ランキング → ⑦ 決算・重要開示（8-K）→ ⑧ 先物・為替・世界の株価・商品 → ⑨ 金利 → ⑩ ニュース → フッター（出典・免責）

### 4.3 Discord 通知（1通の Embed）
- タイトル「2026/09/28(月) NY引け」、S&P500・NASDAQ総合・NYダウ、コメント、騰落数
- 上位・下位セクター、強い・弱いテーマ、金利・為替・商品（SOX・VIX・米10年・2年・ドル円・WTI・金・ビットコイン）、値上がり率上位、出来高急増、ニュース3件、引け後の 8-K 上位3件、注意事項、ページへのリンク
- Embed の左端の色: S&P500 が上昇なら緑、下落なら赤（米国式）
- 失敗時: 「⚠️ NY引けノートの生成に失敗しました」と Actions の実行URL を送る

## 5. 設定と Secrets
| 名前 | 用途 |
|---|---|
| `DISCORD_WEBHOOK_URL` | 通知先（未設定なら通知をスキップ） |
| `SITE_BASE_URL` | 通知に載せるURLの先頭部分（Actions では自動で設定） |
| `SEC_USER_AGENT` | SEC EDGAR へのアクセスに使う User-Agent（例: `usmarket you@example.com`）。未設定なら 8-K をスキップ |

## 6. やらないこと（現時点）
- ザラ場中のリアルタイム更新
- 個別銘柄の詳細ページ
- 売買シグナルや推奨（投資助言にあたるため）
- 記事本文・開示書類の本文の転載
