# 設計判断の記録（簡易ADR）

新しい判断は末尾に追記する。覆すときは元の項目を消さず「→ D-xx で変更」と書き足す。
番号は日本版（summary-jpn-stock-market）の対応する判断にそろえ、米国版で不要になった番号は欠番にしている。

---

## D-01 言語・ツール: Python 3.13 + uv（日本版と同じ）
- 品質ゲートは ruff（lint・format）、mypy --strict、pytest。

## D-02 DailySummary を唯一の契約にする（日本版と同じ）
- 生成側（collect / analyze）と消費側（render / notify）は `src/usmarket/models.py` の `DailySummary` だけでつながる。
- 米国版は SCHEMA_VERSION 1 から始める。日本版から変えた点: `QuoteCategory`（us_index / global）、`SectorPerf`（key・index_weight_pct・etf・etf_change_pct）、`StockMove.sector`、`Breadth`（52週高安・50日/200日線超え）、`Disclosure`（8-K の items、時間外の ah_price / ah_time。PTS と値幅制限の項目はなし）。

## D-03 指数は yfinance で取得する（日本版の TOPIX スクレイピングは不要）
- S&P500・NASDAQ・ダウ・NASDAQ100・ラッセル2000・SOX・VIX はすべて yfinance に四本値がある（2026-09-29 確認）。

## D-04 GICS セクターは「S&P500 構成銘柄を SPY の保有比率で加重した推計値」
- ウエイト: State Street が毎日公開している SPDR S&P 500 ETF（SPY）の保有銘柄 xlsx。時価総額加重の S&P500 とほぼ同じ比率。
- セクター・社名・CIK: Wikipedia「List of S&P 500 companies」（GICS Sector / Sub-Industry / CIK）。SPY の xlsx にはセクターが入っていないため組み合わせる。2026-09-28 時点で 503 銘柄が両方で一致した。
- 両方とも `.cache/master/` に保存して週1回更新する。取得に失敗したら古いキャッシュを使う。
- 公式のセクター指数は無料で取れないので、補助として Select Sector SPDR（XLK など11本）の騰落率を並べる。9/28 の実データでは推計と ETF の差は多くのセクターで ±0.2pt 以内（XLK は上位銘柄の比率に上限があるため差が大きめ）。

## D-05 yfinance はアクセス制限（429）を前提に設計する（日本版と同じ）
- 100銘柄ずつ・欠けた銘柄だけを指数バックオフで再取得。長い履歴は `.cache/prices/` にキャッシュして差分だけ取る。
- 実測（2026-09-29、ローカル）: 初回（約830銘柄×400日）を含めて全体で約70秒。

## D-12 株価キャッシュと銘柄マスタはリポジトリにコミットしない（日本版と同じ）
- SPY の保有銘柄ファイル・Wikipedia の表・yfinance の生の株価は `.cache/` に置く（gitignore 済み）。CI では `actions/cache` で保持する。
- コミットするのは集計結果の `data/daily/*.json` だけ。

## D-13 ランキングは売買代金1億ドル以上の銘柄に限る
- 値上がり率・値下がり率・出来高急増は売買代金（終値×出来高）1億ドル以上。S&P500 構成銘柄のほとんどは超えるが、薄商いの日のノイズを除く。

## D-14 金利: 2年は米財務省の公式値、他は yfinance
- 3ヶ月・5年・10年・30年は CBOE の利回り指数（^IRX / ^FVX / ^TNX / ^TYX）で、四本値があるのでローソク足にする。
- 2年は yfinance に系列がないため、米財務省の Daily Treasury Par Yield Curve の CSV を使う（日本版の FRED DGS2 より公表が早く、引け後の当日中に出る）。前年分はキャッシュし、当年分は毎回取得する。
- 利回りの変化は bp で表示する（日本版と同じ）。

## D-22 実行時刻（米国の引け後、夏時間・冬時間の両対応）
- cron は UTC 固定のため、夏時間（引け 20:00 UTC）と冬時間（引け 21:00 UTC）の両方で引け後になる時刻を選んだ: 20:47（夏時間のみ有効）→ 21:33 → 22:33 UTC（最終）。
- 冬時間の 20:47 UTC は引け前なので、`plan` は前営業日を対象にして「生成済み」で何もしない。
- 最終回以外（`--early`）は、S&P500 のウエイトの95%以上に当日の終値がなければ終了コード75で見送る。
- 日本時間では、夏は 05:47〜、冬は 06:33〜 に届く見込み。

## D-23 決算・重要開示は SEC EDGAR の 8-K（日本版の TDnet に相当）
- 取得元: EDGAR の「Latest Filings」Atom フィード（`browse-edgar?action=getcurrent&type=8-K`、1ページ100件、約3営業日分）。前営業日の引けまでさかのぼるまで、0.3秒ずつあけて最大6ページ読む。公式の無料の仕組みで、利用規約上の問題はない。
- SEC は自動アクセスに連絡先入りの User-Agent を求める（ない場合は 403）。連絡先はユーザーが決めて `SEC_USER_AGENT` に設定する。未設定なら 8-K はスキップし、ページにも出さない。
- 対象: S&P500 構成銘柄とテーマ銘柄（CIK → ティッカーは Wikipedia の CIK 列と SEC の company_tickers.json）。8-K/A（訂正）は除く。
- 分類は項目番号から機械的に付ける: 2.02 決算、1.01 重要な契約、1.02 契約の終了、2.01 買収・売却の完了、5.01 支配権の異動、1.03 破産・更生、2.05 リストラ、2.06 減損、3.01 上場廃止・基準抵触、3.02 未登録株式の発行、4.02 過去決算の訂正、5.02 役員の異動、7.01 Reg FD開示、8.01 その他の重要事項。マイナスの項目（1.03・2.05・2.06・3.01・3.02・4.02）を含むものは neg、それ以外は neutral（8-K の項目だけでは決算の良し悪しは分からない）。
- 表示は注目の項目だけを時価総額の大きい順に最大40件。ランキング・テーマ・セクターの牽引銘柄には、前日引け〜当日引けの開示を1銘柄2件まで付ける。
- 実データ（9/28）: 前日引け〜引け 28件（注目24件）、引け後 15件（注目14件）。

## D-24 開示への株価の反応（当日騰落率 / 時間外取引）と時間外終了後の更新
- 前日引け〜当日引けの開示: 当日の終値ベースの騰落率。
- 引け後の開示: yfinance の5分足（時間外込み）から、引け後〜20:00 ET の最後の約定価格を取り、当日終値と比べる。開示より前の約定しかない場合と、20:00 ET 以降の開示には反応を付けない。日本版の PTS（Yahoo!ファイナンスのスクレイピング）と違い、公開 API の範囲で取れる。
- 時間外取引が終わった後（1:17 UTC、日本時間 10:17）に作り直し、反応を反映する。Discord には送らない。

## D-25 IPO テーマ（動的）
- Nasdaq の IPO カレンダー API（`api.nasdaq.com/api/ipo/calendar`、NYSE の上場も含む）から、直近365日に値付けされた案件を組み入れる。過去の月はキャッシュし、当月だけ毎回取得する。
- 除外: SPAC（社名に Acquisition などを含むもの、ローマ数字で終わるもの）、ユニット・ワラント・ライツ（5文字で U/W/R で終わるティッカー）、調達額が1億ドル未満または不明のもの（小型案件が単純平均を振り回すため）。
- 9/28 時点で94社。
