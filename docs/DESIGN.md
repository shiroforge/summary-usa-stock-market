# 画面設計（DESIGN）

プロダクト名: **NY引けノート**（米国市場の引け後に1ページで相場を振り返るノート。日本版「大引けノート」の姉妹版）

## 方針
- 最初の画面で「今日は上げたか下げたか、何が主導したか」がわかること。詳細は下にスクロールして見る。
- 数字が主役。等幅の数字（IBM Plex Mono、tabular-nums）で桁をそろえる。米国の価格は小数2桁で表示する。
- 色は「上昇・下落」の意味にだけ使う。アクセント色（藍）はリンクや操作できる部分に限る。
- JS なしでも全部読める（ツールチップ・タブ・色の切り替え・拡大チャートだけがJS）。
- 日本の読者向け: 表示文言は日本語、時刻は日本時間が基本（8-K の時刻はカーソルで米東部時間も見られる）。

## トークン
日本版と共通（`src/usmarket/render/static/style.css`）。

| 名前 | ライト | ダーク | 用途 |
|---|---|---|---|
| bg | #F3F5F8 | #0E1219 | ページの背景 |
| surface | #FFFFFF | #161B24 | タイル・カード |
| ink / ink-2 / muted | #141922 / #465064 / #778097 | #E6E9EF / #A9B0BF / #7C8497 | 文字 |
| line | #DEE2E9 | #272E3B | 罫線 |
| accent（藍） | #28487C | #8FB0E6 | リンク・選択状態 |
| green | #1A7C55 | #45C08B | 上昇（既定） |
| red | #C4382F | #F0695C | 下落（既定） |

上昇色は既定で **緑（米国式）**。`data-updown="jp"` で上昇=赤に切り替わる。閲覧者ごとに localStorage（キー `usmarket.updown`）に保存する。

## 書体
- 見出し: Zen Kaku Gothic New 700/900
- 本文: BIZ UDPGothic 400/700
- 数字・コード: IBM Plex Mono 400–600

## レイアウト
- 最大幅 1120px、左右の余白 16px。スマホ幅では1カラム、指数タイルは2列。
- 上部固定バー: ブランド名、前後の営業日・アーカイブ・トレンドへの移動、上昇色の切り替え

## コンポーネント（日本版との差分）
| 名前 | 内容 |
|---|---|
| 指数タイル | S&P500・NASDAQ総合・NYダウ・NASDAQ100・ラッセル2000・SOX |
| 騰落バー | 値上がり・変わらず・値下がり、騰落レシオ、50日線超え・200日線超えの割合、52週高値・安値 |
| セクター | 横棒（ゼロ中心）＋折りたたみの表（セクターETF・牽引・重荷の銘柄チップ） |
| ランキング表 | ティッカー／社名＋セクター／騰落率・出来高（売買代金は $B / $M 表示） |
| 決算・重要開示 | 8-K の時刻（JST）・社名とティッカー・反応（当日／時間外）・分類タグ・項目（原文へのリンク） |
| 拡大チャート | 外部リンクは 株探（米国株）・Yahoo! Finance・Finviz・TradingView |
